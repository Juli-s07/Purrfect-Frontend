## Короткий опис
Цей репозиторій створено для демонстрації фронтенду та його взаємодії з сервером вебсайту "Purrfect".  
Даний проєкт має на меті створити зручний та функціональний сайт, який слугуватиме маркетплейсом для продажу/покупки котиків.  
Заводчики зможуть публікувати своїх котів, вказуючи деталі та умови продажу, а користувачі - шукати тих тварин, які найбільше відповідають їх вподобанням та зв'язуватися із заводчиками для уточнення.  
Головний фокус проєкту - підтримка професійних заводчиків та відкрита історія родини й виховання кожного улюбленця.

## Основні сторінки сайту
- **Основна (Home)** — містить опис сайту, відповіді на поширені питання, віджет цікавих фактів про котів тощо  
- **Коти (каталог)** + можливість переходу на сторінку окремого кота з інформацією про його родовід (Батьків, сестер...)
- **Заводчики** + можливість переходу на сторінку окремого заводчика для перегляду його поточних кошенят, родоводу та архіву минулих виводків.
- **Для покупців** — інформація, яку покупці повинні знати перед покупкою, а також ШІ помічник підбору улюбленця
- **Для заводчиків** — інформація, яку повинні знати заводчики перед розміщенням оголошень  
- **Контакти** — способи зв'язку з адміністрацією  
- **Профіль** — перегляд особистої інформації + подання заявки та підтвердження статусу заводчика за потреби

## Функціонал
### Для гостей
- Лише перегляд усієї інформації (каталогу, профілів заводчиків, родоводу котиків)
- Перегляд цікавих фактів про котів (Cat Facts API)
- Можливість реєстрації
### Для авторизованих користувачів (потенційних покупців)
- Функціонал для гостей
- Логін
- Перегляд та редагування профілю + подання заявки на підтвердження статусу заводчика за потреби
- Зберігати котиків у "обране"
- Бачити контакти заводчиків
- Залишати відгуки
- Можливість комунікувати з ШІ ботом
### Для заводчиків
- Функціонал для авторизованих користувачів (крім лишати відгуки самому собі)
- Можливість додавати та редагувати пости своїх котів
- Керування генеалогічними зв'язками котів (вказання батька та матері)
- Зміна статусів котів та збереження проданих тварин у категорії «Випускники» (портфоліо розплідника)
### Для адміністраторів
- Практично все: редагування та видалення постів, користувачів, заводчиків за необхідності
- Підтвердження статусу заводчиків

## Цікаві деталі
- **Підтвердження статусу заводчика через надсилання форми, яку потім "перевіряє" адміністратор** Під час очікування профіль заводчика має лише функціонал авторизованого користувача, допоки не відбудеться підтвердження   
- **Нотифікації на email** (при реєстрації, щоб упевнитись, що пошта реальна та належить користувачу)  
- **Інтерактивні котячі династії (Pedigree Tree):** Відмова від стандартної CRUD-логіки видалення проданих тварин. Вони отримують статус «Випускник» і формують публічне портфоліо заводчика. Завдяки рекурсивним зв'язкам у БД користувачі бачать візуальне дерево предків кожного кошеняти.
- **AI Smart Match:** Інтеграція з ШІ для підбору котика за анкетою покупця. Алгоритм буде аналізувати побажання користувача та підбирає котів з тих, які наразі є в наявності в БД.
- **Cat Facts API Integration:** Використання стороннього REST API для відображення випадкових цікавих фактів про котів для підвищення інтерактивності платформи.

## Як запустити проєкт
### На бекенді:
1. Створити та активувати віртуальне середовище
```bash
python -m venv .venv

# for linux/macos
source .venv/bin/activate
# for Windows:
.venv\Scripts\activate
```

2. Встановити залежності  
```bash
pip install -r requirements.txt
```

3. Запустити міграції, щоб створити БД
```bash
python manage.py migrate
```

4. Запустити сервер  
```bash
python manage.py runserver
```

### На фронтенді:  
1. Запустити через окремий термінал (одночасно з бекендом)  
```bash
python -m http.server 5500
```
2. Якщо проєкт вже запускався, то варто очистити кеш командою `ctrl+shift+R`

Сайт буде доступним за адресою http://localhost:5500

**P.S. Практично весь фронтенд (html, css, js) буде реалізовано за допомогою ШІ з ручною перевіркою правильності роботи.**
